# Ayushi Choudhury | Portfolio Website

A responsive personal portfolio website showcasing my work in development, design, and art.

**Live site:** https://ayushichoudhury850-a11y.github.io/portfolio-website/
**Repository:** https://github.com/ayushichoudhury850-a11y/portfolio-website

## Project Overview
**Purpose:** To present my projects, skills, and contact details in one place, along with a separate gallery for my artworks.

**Target audience:** Recruiters, collaborators, fellow students, and creative people.

## Features
- Responsive layout that works on desktop and mobile
- Rotating role text on the home page
- Scroll-reveal animations
- Selected works section with project cards
- Separate art gallery page
- Contact form with validation

## Technology Stack
- HTML5
- CSS3 (Grid, Flexbox, custom properties, media queries)
- JavaScript
- Google Fonts (Cormorant Garamond, DM Sans)
- Hosted on GitHub Pages

## Setup Instructions
1. Download or clone this repository:
   `git clone https://github.com/ayushichoudhury850-a11y/portfolio-website.git`
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or build tools are needed.
